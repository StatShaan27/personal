# Ishaan — class archive

Page: https://statshaan27.github.io/personal/ishaan.html

The page includes 27 class-note PDFs from the Teaching [Main] Trello board, dated 13 December 2025–8 July 2026. These are links to the original Trello attachments; the PDFs have not been copied into GitHub. A Trello link beside each class opens its source entry.

The Trello Books card had no books. Add books and future notes on the `main` branch using:

| Type | Example path |
| --- | --- |
| Book | `ishaan/books/Book title.pdf` |
| Class note | `ishaan/notes/2026-11-05/Topic title.pdf` |

Months, dates and PDF titles are discovered automatically for GitHub uploads. Put multiple PDFs for the same class in the same date folder. For a new date folder in GitHub's web interface, create `notes/YYYY-MM-DD/.gitkeep` inside `ishaan`, commit, then use **Add file → Upload files** in that folder. Allow Pages to publish, then click **Refresh**.

`catalog.js` holds the imported Trello references and their original class dates. It is a snapshot, not a continuous Trello sync. To add more Trello links, update that catalog. GitHub uploads appear alongside the imported references.

The homepage and search index do not link to this archive. As with all public GitHub Pages content, the unlisted link is not password protection.
